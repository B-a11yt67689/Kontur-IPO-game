# IPO-015 — Определить результат стартового броска

## Требования

Добавить `backend/app/starting_bonus.py` с неизменяемым dataclass
`StartingBonus(roll, code, description, action_point_bonus, client_bonus,
 deferred)` и чистой функцией `resolve_starting_roll(roll: int) -> StartingBonus`.
`code` — Literal из кодов таблицы ниже. Результат детерминирован и не изменяет
baseline. Значения не-int и bool отклоняются TypeError; вне 1–10 — ValueError.

| d10 | code | Эффект |
| --- | --- | --- |
| 1 | action_points | +10 очков в начале первого акта |
| 2 | virality | +1 шаг виральности один раз |
| 3 | retention | +1 шаг удержания один раз |
| 4 | orders_per_client | +1 шаг количества покупок один раз |
| 5 | average_price | +1 шаг среднего чека один раз |
| 6 | payment_conversion | +1 шаг конверсии в оплату один раз |
| 7 | experiment | +1 эксперимент один раз |
| 8 | infrastructure | +2 балла инфраструктуры один раз |
| 9 | clients | +10 клиентов на старте |
| 10 | interest_free_loan | Выплата кредита без процентов один раз |

Только 1 и 9 немедленные: соответственно action_point_bonus=10 или
client_bonus=10, остальные прибавки нулевые; deferred=False. У остальных
прибавки нулевые, deferred=True: это сохраняемое право на одно применение,
его активация вне текущих задач. description — короткий русский текст эффекта.
Случайность будет только на сервере запуска акта, не внутри resolver.

## Приёмка и файлы

Все десять соответствий и числовые эффекты проверены независимыми ожидаемыми
значениями; границы/типы, frozen dataclass, повторяемость и неизменность
build_act_one_baseline. Файлы: `app/starting_bonus.py`, `tests/test_starting_bonus.py`.
