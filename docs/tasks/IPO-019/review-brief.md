# IPO-019 — brief независимого ревью

Проверить [задачу](brief.md), [отчёт](report.md) и полный пакет фактических
изменений с идентификаторами снимка. Общие решения: [первый акт](../../ACT-ONE-DECISIONS.md).
Не ограничивать проверку заявлением автора о готовности.

## Основные риски

- Формулы Excel и Decimal pure-кода сохраняются, реклама вычитается один раз.
- API доступен только cfo; номер акта и начальный баланс берутся с сервера.
- Нефинитные/отрицательные/неверные/лишние входы дают422, включая сырой JSON NaN; нет500 или отражения секретов.
- Предпросмотр read-only: баланс/клиенты/AP/команды/фаза/бросок/бонусы не меняются.

## Формат заключения

Роль `.codex/agents/ipo-task-reviewer.toml`: Spec Compliance → Strengths →
Issues (Critical/Important/Minor) → Assessment. Ревью read-only, со ссылками
на файл и строку. Не повторять полный suite без конкретной причины; проверить
доступные свидетельства запуска. Существенные замечания исправляются исполнителем
и повторно проверяются до одобрения.
