# Первый акт: решения для IPO-015–IPO-020

16 ноября 2026. Пользователь поручил составить описания задач самостоятельно
на основе контекста. Ниже отделены параметры источников от выбранных решений
первого среза. Поздние пользовательские решения могут их заменить.

## Источники

- «Разбор правил IPO»: старт, цикл актов, найм и очки действий.
- «Метрики и формулы IPO» и исходное извлечение Excel: денежные формулы.
- Итоги встречи 22 октября: роли имеют финальное слово в своей зоне.
- Текущий baseline IPO-014/решение C: две junior, 130 AP без +20 за команды,
  675.00 денег, 60 клиентов, capacity2, hiring0, три эксперимента.
- Holst JSON, группа 7496f416-73d3-4164-8dca-3dc799724e46: номера и тексты
  стартовых карточек сопоставлены по координатам, а не порядку текстового экспорта.

## Выбранная трактовка

1. d10: детальный раздел стартового бонуса и десять карточек имеют приоритет
   над одиночным d12 в навигаторе. Соответствия 1–6,8–10 видны по совпадающим
   координатам карточек и чисел; номер7 сдвинут вниз и выведен отдельно
   (объект5a7b27d0-8e19-4451-a134-4d63fdd88e6e), единственная оставшаяся карточка
   c9412a3b-00b2-4804-956c-bc59733c29e6 — дополнительный эксперимент. Это явно
   зафиксированное восстановление, не доказанное совпадение координат номера7.
2. Немедленно применяются только бонусы1(+10AP) и9(+10клиентов). Остальные —
   доступное одноразовое право. «+1 к метрике» означает шаг трека, а не +1 к доле;
   активация этих прав и эксперименты за пределами данного набора задач.
3. Администратор начинает акт после капитана и четырёх назначенных ролей.
   Статус act_one, один серверный бросок, повтор возвращает сохранённое состояние.
4. Первая покупка стратегии стоит30AP и увеличивает вместимость2->3. Фактический
   состав остаётся две junior, дополнительных AP/экспериментов в этом акте нет.
   Действие разрешено people; чтение — любому участнику; P&L preview — cfo.
5. P&L по готовым входам — расчёт/предпросмотр, не завершение акта: постоянный
   баланс и фаза не меняются. API фиксирует номер акта1 и берёт начальный баланс
   с сервера. Удержание/виральность, округление клиентов, кредиты, риски и полный
   переход к следующему акту не добавляются.
6. Денежные расчёты Decimal, без float и дополнительного округления до копеек.
   JSON возвращает Decimal строками. Ошибки и HTTP-права перечислены в brief.
